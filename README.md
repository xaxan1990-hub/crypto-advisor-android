# Крипто-советник для Android

Мобильная версия [настольного советника](https://github.com/xaxan1990-hub/crypto-advisor). Работает на телефоне и планшете, без сервера пользователя и API-ключей. Первый запуск с котировками требует интернета. Нужны Android 8 или новее и актуальный Android System WebView.

[Скачать APK из выпусков](https://github.com/xaxan1990-hub/crypto-advisor-android/releases). Выпуск 0.2.0 подписан стабильным release-ключом: ключ и пароли хранятся в GitHub Actions Secrets, а не в Git. Благодаря этому обновления 0.2.0+ можно ставить поверх предыдущей версии с сохранением данных. Первый переход с 0.1.0 может потребовать удалить старую debug-подпись — подробности ниже.

В приложении есть раздел **Проверка → Версия и обновления**: он показывает установленную версию, умеет сверять её с последним релизом GitHub (для публичного репозитория) и открывает страницу Releases для скачивания APK. Для приватного репозитория GitHub API без токена недоступен, поэтому используется ссылка на Releases.

## Что доступно

- **Рынок.** До 50 монет CoinGecko после фильтров настольного приложения. Поиск, сортировка, цена и изменения за сутки, неделю и месяц. Кнопка расчёта загружает истории по две одновременно. Сводные баллы учитывают только рассчитанные монеты с весом по корню из капитализации.
- **Монета.** Дневной график, MA50, MA200, RSI, волатильность и объяснения для 7, 30 и 180 дней. На устройстве исполняются три обученные модели LightGBM. Рядом с оценкой видны надёжность и фактический вес модели.
- **Новости.** Девять исходных RSS-лент, сортировка по времени, выделение важных событий и открытие статьи в браузере.
- **Портфель.** Покупки и продажи в рублях: вводятся фактически потраченные/полученные рубли и количество крипты, цена за монету считается автоматически. Стоимость, средняя цена, реализованная и нереализованная прибыль считаются в рублях; есть переключатель ₽/$ и курс ЦБ РФ (при недоступности — USDT/RUB). При отсутствии котировки приложение отмечает неполную оценку.
- **Симулятор.** В карточке монеты можно сравнить еженедельную покупку, покупки по страху и жадности, по оценке советника и разовую покупку. Для исторических сигналов используются сохранённые веса только предыдущих лет.
- **Проверка.** Результаты исторической калибровки и отдельный журнал собственных прогнозов телефона. Прогноз записывается один раз в день на монету и горизонт. Для проверки используется закрытие целевого дня при следующем анализе монеты.

## Расчёт и данные

Исходная калибровка и модели взяты из коммита [d1fef39](https://github.com/xaxan1990-hub/crypto-advisor/commit/d1fef39caaf2742e3c21e6c40ed3775c15dc1da3). В приложении сохранены режимные веса, коэффициенты надёжности, правила активизации факторов, признаки и числовые деревья. Для переноса новой калибровки выполните `python tools/import_models.py /путь/к/crypto-advisor` и запустите тесты.

Котировка в заголовке может быть новее оценки. Для неё используются последние закрытые дневные свечи. Binance предоставляет до 1000 дней, запасной источник CoinGecko — до 365. Пара Binance сверяется с ценой и датой CoinGecko для защиты от совпадения тикеров. Отдельно загружаются индекс [Alternative.me](https://alternative.me/crypto/fear-and-greed-index/) и недавний funding при совпадении пары. Недостающие данные на экране помечаются. Исторический симулятор использует доступное телефону окно данных, без комиссий.

Для рублёвого портфеля курс USD/RUB берётся с [ЦБ РФ](https://www.cbr-xml-daily.ru/) и кэшируется на 12 часов. Если ЦБ недоступен, используется USDT/RUB с CoinGecko; при отсутствии обоих показывается сохранённый курс или пометка о неполной оценке.

Android-версия показывает новости на языке источника. FinBERT, машинный перевод и еженедельное переобучение пока доступны в настольной версии. Новости пока не вносят вклад в баллы на телефоне. Калибровка, длина истории, момент закрытия свечи и доступность источников влияют на результат. Исторические показатели не гарантируют будущую доходность.

## Подпись и обновления

Release APK собирается workflow `.github/workflows/android-release.yml` при пуше тега `v*`. В GitHub Actions должны быть заданы секреты:

- `ANDROID_KEYSTORE_BASE64` — keystore в base64;
- `ANDROID_KEYSTORE_PASSWORD` — пароль хранилища;
- `ANDROID_KEY_ALIAS` — alias ключа;
- `ANDROID_KEY_PASSWORD` — пароль ключа.

Локальная сборка подписанного APK:

```sh
ANDROID_KEYSTORE_FILE=/путь/release.keystore \
ANDROID_KEYSTORE_PASSWORD=... \
ANDROID_KEY_ALIAS=crypto-advisor \
ANDROID_KEY_PASSWORD=... \
./gradlew :app:assembleRelease
```

Файл ключа и `signing.env` лежат только на устройстве в `~/.config/crypto-advisor/`; сделайте резервную копию, иначе будущие обновления нельзя будет подписать тем же ключом. Смена ключа означает, что Android не установит APK поверх старой версии — потребуется удаление приложения.

Версия 0.1.0 была debug-подписью, поэтому первый переход на 0.2.0 может потребовать удалить её. Начиная с 0.2.0 подпись стабильная, и последующие версии ставятся поверх.

## Сборка

Откройте репозиторий как обычный Android-проект или используйте JDK 21, Android SDK Platform 37.0 и Build Tools 36.0.0.

```sh
./gradlew :app:assembleDebug :app:lintDebug
node --test tests/*.test.js
```

APK появляется в `app/build/outputs/apk/debug/app-debug.apk`. В настроенном Termux можно выполнить `gradle :app:assembleDebug :app:lintDebug`, используя установленный Gradle и ARM64-версию AAPT2. Путь к AAPT2 задаётся в локальном `~/.gradle/gradle.properties` свойством `android.aapt2FromMavenOverride`.

## Устройство проекта

Kotlin обслуживает жизненный цикл, внешние ссылки, HTTPS-запросы к разрешённым источникам, курс валют и дисковый кэш. Интерфейс WebView и расчёты расположены в `app/src/main/assets`; операции портфеля и расчёт средней цены/прибыли — в `portfolio.js`. Портфель (`portfolio-v2`; старый `portfolio-v1` мигрирует в рубли по текущему курсу) хранится в локальном хранилище приложения, журнал — в IndexedDB. Удаление данных приложения удалит оба. В GitHub личные записи не отправляются.

В GitHub Actions вручную запускается проверка debug APK на эмуляторе Android 15: workflow собирает его из исходников. Она проходит сценарии рынка, карточки, симулятора, покупки и продажи в портфеле после перезапуска, журнала, RSS и поиска на контролируемых котировках. Отдельный workflow `.github/workflows/android-release.yml` собирает debug APK при пуше тега `v*` и прикладывает его к GitHub Release. Для обновления версии поднимите `versionCode`/`versionName`, создайте тег — APK появится в Releases.
