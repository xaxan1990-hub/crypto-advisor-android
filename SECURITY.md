# Безопасность

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии. Обновляйтесь через GitHub Releases или кнопку «Обновить приложение».

## Как сообщить об уязвимости

Не создавайте публичный Issue с описанием эксплойта. Используйте приватный GitHub Security Advisory:

https://github.com/xaxan1990-hub/crypto-advisor-android/security/advisories/new

Укажите версию, шаги воспроизведения и возможные последствия. Ответ постараюсь дать в разумный срок.

## Что уже сделано

- Release APK подписывается стабильным ключом; встроенный updater проверяет подпись скачанного APK перед установкой.
- WebView не имеет доступа к файлам, внешние ссылки открываются в браузере, JavaScript-мост ограничен узкими методами.
- В репозитории нет keystore, паролей и токенов; они хранятся в GitHub Actions Secrets.
- Сетевые запросы идут только по HTTPS к разрешённым источникам.
- Портфель и журнал хранятся локально; экспорт выполняется только по действию пользователя.

## Вне области

- Компрометация самого устройства или установленной прошивки.
- Подмена публичных рыночных данных их источниками.
- Приватные ключи и seed-фразы: приложение их не запрашивает и не хранит. Никогда не вводите их в сторонние приложения.
