# Приватность

«Крипто-советник для Android» не требует аккаунта, не содержит рекламы и не собирает аналитику.

## Что хранится на устройстве

- портфель и список операций — в локальном хранилище WebView (`portfolio-v2`);
- уведомления о цене — в приватных настройках приложения Android;
- журнал прогнозов — в IndexedDB;
- кэш котировок, курсов, новостей и моделей — в приватной папке приложения;
- настройки валюты и диапазона графика — в локальном хранилище.

Эти данные не отправляются разработчику. Они удаляются вместе с данными приложения или при удалении приложения. Резервную копию портфеля можно сохранить в JSON-файл через «Портфель → Экспорт»; файл создаётся по выбору пользователя и может содержать личные записи о покупках.

## Сетевые запросы

Приложение обращается только к публичным источникам:

- CoinGecko — котировки, история цен, поиск монет;
- Binance — дневные свечи и funding;
- ЦБ РФ (cbr-xml-daily.ru) — курс USD/RUB, включая архив по датам;
- Alternative.me — индекс страха и жадности;
- RSS-ленты криптоизданий;
- GitHub — проверка релизов и скачивание APK.

Эти сервисы получают обычные технические данные запроса (IP-адрес, User-Agent, запрошенный URL). Приложению не передаются приватные ключи, seed-фразы, пароли бирж или платёжные данные. Приложение не подключается к биржам и не совершает сделки.

## Уведомления

Проверка ценовых целей выполняется локально через WorkManager. Список целей хранится на устройстве; на сервер разработчика ничего не отправляется. Уведомления можно запретить в настройках Android.

## Вопросы

Проблемы приватности можно описать в GitHub Issues или через приватный Security Advisory, если речь об уязвимости.
